## 实际浏览器检查

| 范围 | 实际观察 |
|---|---|
| 桌面 1440、平板 768、手机 390 与窄屏 320 CSS px | 截图检查信息层级、换行、列布局/折叠；DOM 的页面滚动宽度均未超过视口宽度。1280 宽完成恢复交互。 |
| 正常调整 P3 → P2 | partial 不可审批；完整提案可审查；提交中不提前更新工单，收到模拟 receipt 后才更新优先级及处理记录。 |
| 键盘与对话框 | Tab 到取消/批准，Return 执行批准；焦点可见。Escape 关闭审查后恢复到“审查这项变更”。生成和核对时焦点保留在助手容器。 |
| 生成中断 | 进入 interrupted；没有审查按钮；工单仍为 P3；显示重新整理入口。 |
| 结果待确认 | 显示 unknown，新的起草按钮禁用，工单投影仍为 P3；“核对处理结果”完成后显示 REC-2048-01，投影为 P2，处理记录由 3 条变为 4 条。 |
| 用户视图 | 只显示 2 条演示本人请求；草稿仅提供“提交给服务台审查”，没有批准入口。 |
| 搜索无匹配 | 显示空结果及调整关键词/状态提示。 |
| 浏览器错误 | 本次检查结束时读取到的 console error 列表为空。 |
